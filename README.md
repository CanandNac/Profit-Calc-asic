# Profit Calc

Android-приложение (Capacitor) из `www/index.html`.

## Как получить APK
1. Создай репозиторий на GitHub и залей ВСЕ файлы из этой папки (включая скрытую папку `.github`).
2. Открой вкладку **Actions** → дождись зелёной галочки (3–6 минут).
3. Открой завершённый запуск → внизу **Artifacts** → скачай `ProfitCalc-apk` (zip) → внутри `ProfitCalc.apk`.
4. Перекинь APK на телефон и установи (разреши установку из неизвестных источников).

Повторный запуск: Actions → Build APK → Run workflow.
